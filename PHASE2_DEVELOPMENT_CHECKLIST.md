## How to use this file

- Work from top to bottom. Do not start a later gate when an earlier gate would invalidate the work.
- Give every branch, commit, agent task, and result the checklist ID shown here.
- Mark an item complete only after its acceptance check passes and evidence is recorded in the completion log.
- Preserve historical results. New authoritative results go in one checksummed final-results directory.
- Do not describe calibration draws as a posterior unless the inference method has been validated as one.

Status convention:

- `[ ]` not complete
- `[x]` complete and verified
- `[~]` in progress (temporary; replace with `[ ]` or `[x]` before handoff)

  - **Accept:** unit tests against a known toy posterior plus posterior-predictive checks.
  - Implemented 2026-08-22: Toni et al. (2009) importance weights + Beaumont et al. (2009) adaptive PMC kernel in `run_abc_smc_calibration.py`; `TestToyPosteriorRecovery` validates against a closed-form 1-D toy target (weighted mean/variance/ESS all match analytically). Adversarial code review 2026-09-06 found and fixed one real bug: `_load_anchor_particle` (used by `--anchor-config`/`--anchor-glob`) never validated extracted parameter values against the current run's calib_space `[min,max]` bounds — an anchor from an older/wider calib_space vintage could silently inject an out-of-bounds value. Fixed with an explicit bounds check plus two new tests. **Not yet accepted**: the posterior-predictive check (compare a real weighted-resample's simulated output against historical targets) has not been formally executed/recorded.

- [~] **UNC-02B — If retaining SNPE, repair and validate sequential inference.**
  - Apply proposal correction; fix paths/environment; add simulation-based calibration and posterior-predictive checks.
  - **Accept:** active rounds contain particles, bounded posterior samples are produced, diagnostics pass, and results are reproducible.

One real bug found and fixed 2026-09-06: the round-retry fallback path didn't pass `skip_append=True`, silently double-appending a round's data into sbi's accumulated dataset whenever proposal-corrected training failed and retried; fixed and extracted into a directly-testable `_train_round_with_fallback()` helper. **Accept criterion still not met**: rounds routinely get 0 posterior samples. ## Gate 4 — Quantify engineering approximations before changing them

**Exit condition:** only material changes enter the production engine, and every such change triggers recalibration review.

- [x] **ENG-01 — Quantify deterministic background-mortality rounding.**
  - Compare aggregate expected deaths with cellwise rounded deaths by year and subgroup.
  - **Accept:** materiality threshold and result are documented; use aggregate-preserving allocation if material.
  - Fixed 2026-09-06: `demography.py`'s two background-mortality functions (`_calculate_constant_mortality`, `_calculate_life_table_mortality`) used cellwise `np.round(pop * rate)`, inconsistent with every other deterministic event draw in the model (`run_v3.py`'s aggregate-preserving `_deterministic_allocate_events`). Extracted that allocator into a new shared module `stochastic_allocation.py`; both `run_v3.py` and `demography.py` now import and call it, so all deterministic draws round the same way. Quantified materiality by isolating just this change (holding every other draw fixed): full 1975-2025 deterministic run of `configs/V13.22_20260604_nearfit_rank001_basecase.json` — background deaths shift by +1,032 of 7,225,644 (+0.014%), nonzero in 190/204 quarterly steps. Effect is small in aggregate but confirms cellwise rounding was silently dropping rare deaths almost every step, as the audit predicted; switched to the aggregate allocator regardless of the small magnitude, for consistency with the rest of the deterministic path (which PSA relies on). No regressions: reran the full suite (1,507 passed / 59 failed / 2 skipped / 5 errors) and confirmed by temporarily reverting the fix that all 59 failures reproduce identically on the pre-fix code — none attributable to this change.
