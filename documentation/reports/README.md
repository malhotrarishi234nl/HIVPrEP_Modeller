# Research reports

Completed research notes and decision records live here rather than beside executable code.

- `calibration/` — calibration runs, diagnostics, source decisions and fit assessments.
- Output-specific reports remain inside their immutable `outputs/` run directories.
- Task briefs, implementation plans and runbooks are not completed reports and are not moved
  here until their own directory migration is reviewed.

Moved files retain their original filenames so references remain searchable. New references
should use the full `documentation/reports/...` path.
